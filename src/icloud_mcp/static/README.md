Optional connector icons. No image files ship with the source.

If you add `favicon.ico`, `icon-180.png` and/or `icon-32.png` here, the server serves them at `/favicon.ico`,
`/apple-touch-icon.png`, `/icon.png` and `/icon-32.png` and advertises them in its MCP server info. Use artwork you
have the right to use. Note that Claude does not currently display custom icons for custom connectors.
