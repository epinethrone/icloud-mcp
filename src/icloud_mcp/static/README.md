Connector icons, generated from the project logo in `assets/logo.svg` (MIT, like the rest of the project).

The server serves `favicon.ico`, `icon-180.png`, `icon-32.png`, `icon-192.png` and `icon-512.png` at `/favicon.ico`,
`/apple-touch-icon.png`, `/icon.png`, `/icon-32.png`, `/icon-192.png` and `/icon-512.png` (the last two are the dashboard's app icons), and advertises them in its MCP server info. To use your own artwork, replace these files; use artwork you have the
right to use. Note that Claude does not currently display custom icons for custom connectors.
